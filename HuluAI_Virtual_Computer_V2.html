Bedrock starter add-on builder

Builds a real starter item add-on structure with Behavior Pack, Resource Pack, texture, recipe, manifests, and a mini guide. It does not pretend to generate custom dimensions or a complete game.

Ready. Configure the item, then build.

What the builder creates

Behavior PackManifest, item definition, optional recipe.
Resource PackManifest, item texture map, generated PNG.
Mini guideImport, enable packs, test recipe, inspect logs.
A custom dimension needs registered dimension files and a supported travel/teleport mechanism. This starter builder does not claim to generate that system.

Build workflow

After creating the files, inspect them in Workspace, use Run all project checks, then import the .mcaddon into Minecraft Bedrock to test it in-game.

1. Configure item details 2. Build starter pack 3. Run static checks 4. Import into Minecraft 5. Test item, texture, and recipe in a new test world

What the backend needs to do

The UI cannot train or improve weights by itself. Connect it to your real training/model runtime before expecting model learning.

GET /health Should return HTTP 200 and a small JSON status. POST /chat Request includes: message, prompt, workspace_files. Response may include: response, reply, output, and optional files: [{ name, content }]. Training Requires a separate authenticated training service or notebook/runtime. This website does not run model training or save model checkpoints.
Do not put private API keys in this public GitHub Pages website. Keep secrets on a server. Only connect to a backend you control and trust.
